다음 원칙, 지침 등의 내용을 기준으로 특정 유저와 결이 잘 맞는 최대 유저 3명을 매칭하라.

실제로 매칭해야 할 "Input"은 프롬프트 가장 마지막 문단에 있으며, 너는 Ouput Format에 맞게 오로지 Output만 작성하면 된다. 그외 어떠한 부가 설명도 적지 마라.

**강조한다. 너는 오로지 JSON만 반환한다. 다른 어떠한 말도 하지 않는다.**

## Input Format

```json
{
  "users": [
	  {
	    "id": 1,
	    "tagNames": ["tagName1", "tagName2", ... ]
    },
    ...
  ],
  "requester": {
    "id": 10,
    "tagNames": ["tagName5", ...]
  }
}
```

- 매칭이 가능한 모든 유저 리스트가 주어진다.
    - 유저 ID, 태그 이름 리스트
- 매칭을 희망하는 유저의 ID와 그 유저가 가진 태그 이름 리스트가 주어진다.

## Output Format
{
  "matchedUserIds": [11, 50, 100]
}

- requester와 잘 맞는 최대 3명의 유저 ID 리스트를 반환한다.

## 매칭 원칙

- input에 모든 유저와 요청 유저가 있는데, 요청 유저와 동일한 ID를 갖는 유저 ID는 매칭 결과에 포함하면 안 된다.
- 태그는 일반적으로 5~7개 정도 인입이 되며 최대한 비슷한 태그를 갖는 유저를 매칭해야 한다.
- 만약 적합한 유저가 3명까지 없다면 0~2명까지 제안해도 좋다.

## 백그라운드 내용

**우리 프로젝트의 핵심 메커니즘**
사용자들이 자신의 "일상의 결"을 효과적으로 포착하고 공유할 수 있도록 구조화된 이미지 업로드 방식을 사용한다. 일상의 결은 오로지 이미지 한 장으로 결정되는 것은 아니고, 수많은 이미지들을 통해 완성된다.

**일상의 결이란?**

- 개인의 하루하루 삶에서 반복되는 흐름, 감정, 패턴, 그리고 생활 리듬을 의미함.
- 단순한 관심사나 취미를 넘어 개인이 실제 일상에서 만들어가는 삶의 질감과 방식으로, 이를 통해 비슷한 생활 패턴을 가진 사람들 사이에 형성되는 깊은 공감대를 의미함.
- 혼자 노는 것을 좋아하는 사람의 일상의 결
    - 아침에 혼자 마시는 커피와 창가에서 읽는 책 사진
    - 점심 시간에 혼자 방문한 조용한 카페의 구석자리
    - 저녁에 집에서 직접 요리한 한 인분 식사
    - 밤에 방 안에서 조명 하나만 켜고 진행하는 취미 활동(그림, 글쓰기, 독서)
    - 주말 아침 홀로 산책하는 공원 풍경
    - 자신만의 공간을 정돈하고 꾸미는 모습
    - 침대에서 좋아하는 시리즈를 혼자 시청하는 모습
- 단체 활동을 적극적으로 하는 사람의 일상의 결
    - 아침 러닝 크루와 함께한 조깅 사진
    - 점심시간에 여러 친구들과 함께하는 식사 모습
    - 저녁 시간 동호회 활동에 참여하는 모습
    - 주말 봉사활동 단체와 함께하는 장면
    - 친구들과의 홈파티나 모임 준비 과정
    - 스포츠 팀 활동이나 그룹 레슨 참여 모습
- 두 유형의 사용자는 일상의 흐름과 패턴이 확연히 다르지만, 각자의 "일상의 결"을 통해 비슷한 생활 패턴과 가치관을 가진 사람들과 연결될 수 있음.
- 예를 들어, 혼자 노는 것을 좋아하는 사람은 조용하고 개인적인 시간을 소중히 여기는 다른 사람들과, 단체 활동을 좋아하는 사람은 활발한 사회활동과 다양한 모임을 즐기는 사람들과 자연스럽게 연결됨.

**일상의 결로 어떻게 위 문제를 해결하는가?**

- 표면적 관심사가 아닌 실제 삶의 모습을 통한 연결로 관계의 깊이와 진정성을 향상할 수 있음.
- 비슷한 "일상의 결"을 가진 사람들 간의 자연스러운 공감대로 무례한 소통이 감소함.
- 관련 심리학 이론
    - 유사성-매력 이론(Similarity-Attraction Theory)
        - Byrne(1971)의 연구에 따르면, 사람들은 자신과 비슷한 태도, 가치관, 배경을 가진 사람들에게 더 호감을 느끼고 우호적인 태도를 보임.
        - 유사성은 소통의 용이성을 높이고 충돌 가능성을 줄여줌.
    - 사회적 정체성 이론(Social Identity Theory)
        - Tajfel & Turner(1979)의 연구는 사람들이 자신이 속한 집단(내집단)의 구성원들에게 더 우호적이고 협력적인 태도를 보인다는 것을 발견
        - 일상 패턴의 유사성은 같은 집단에 속했다는 인식을 강화할 수 있음

⇒ 이렇게 일상의 결이 맞는 사람끼리 매칭을 해 주는 것이 최종 목표이다!
