다음 원칙, 지침 등의 내용을 기준으로 첨부한 이미지로부터 관련성이 있는 태그 5 ~ 10개를 추출하라. 단, 성격이 비슷하거나 중복된 태그는 1개로 합친다.

이때 output은 “#tag1, #tag2, … , #tag10” 형식으로 반환하고 그 외 어떠한 설명도 추가하지 마라.
(예시 output: #A, #B, #C)

---
### 태그 생성 원칙
- 표면적 특징보다 사용자의 생활 패턴과 일상의 결을 반영하는 태그를 생성할 것
- 이미지와 맥락 정보를 종합적으로 분석하여 사용자의 생활 방식을 가장 잘 대표하는 태그 추출
- 단순 객체 인식이 아닌, 이미지의 분위기와 맥락 정보를 결합한 의미 있는 태그 생성
- 유사한 생활 패턴을 가진 사용자 간 매칭에 유용한 태그 우선시

### 태그 카테고리 및 예시

**1. 일상 패턴 태그**
- 생활 리듬과 루틴을 나타내는 태그
- 예: #아침형인간, #늦은저녁활동, #규칙적생활, #주말요리사, …

**2. 감정 상태 태그**
- 이미지와 맥락에서 드러나는 감정적 특성
- 예: #평온한시간, #집중상태, #소소한기쁨, #사색중, …

**3. 공간 및 환경 태그**
- 사용자가 시간을 보내는 공간의 특성
- 예: #미니멀공간, #자연친화적, #아늑한실내, #도시적분위기, …

**4. 활동 스타일 태그**
- 활동 방식이나 취향을 나타내는 태그
- 예: #혼자만의시간, #소규모모임선호, #창의적취미, #규칙적운동, …

**5. 가치관 관련 태그**
- 이미지에서 유추할 수 있는 중요시하는 가치
- 예: #자기계발중심, #관계중시, #균형있는생활, #미적가치추구, …

**6. 시간 투자 패턴 태그**
- 시간을 어디에 투자하는지 나타내는 태그
- 예: #독서시간, #야외활동, #취미몰입, #자기관리시간, …

**7. 소통 스타일 태그**
- 타인과의 교류 방식 특징
- 예: #깊은대화추구, #간결한소통, #공감능력, #조용한교류, …

### 태그 형식 지침

- 간결성: 2-3단어 이내로 구성
- 형태: 한글 해시태그 형태(#포함)
- 수량: 이미지당 5-10개의 의미 있는 태그 생성
- 추상성: 직접적 객체명 외에 일상의 결을 반영하는 추상적 개념도 포함

### 태그 품질 검증 기준

- 표면적 특징(예: 단순 객체명)보다 생활 패턴을 반영하는가?
- 사용자 매칭에 유용한 정보를 담고 있는가?
- 한 카테고리에 편중되지 않고 다양한 측면을 골고루 담고 있는가?
